# Instructions projet

Avant toute modification :

* Lire `TEST_ENVIRONMENT_CHANGELOG.md`.
* Lire `docs/ETAT_PROJET.md` si le fichier existe.
* Lire la documentation metier concernee dans `docs/`.
* Faire des modifications ciblees et conserver l'existant.

Branches :

* `main` = production.
* `codex-setup-staging-workflow` = vraie branche test reliee au projet Vercel test.
* Travailler d'abord sur `codex-setup-staging-workflow`.
* Ne pas pousser sur `main` sans validation utilisateur explicite.

Documentation continue :

* Quand une page ou une logique est validee, mettre a jour `docs/ETAT_PROJET.md`.
* Documenter le fonctionnement, les pages liees et ce qui reste en cours.
